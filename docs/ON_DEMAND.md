# 1.2.0 按需课程流程

本版本在 test2 上将公开入口改为半自动操作。原有仿真鼠标轨迹、悬停、按下/抬起和最终点击，以及课内播放目标、短时长优先和有界恢复机制保持原有规则。

## 操作顺序

1. 点击「获取课程列表」：仅通过网站课表入口读取所有分页中正在上的课程，读取完成后停止。
2. 选择一门课点击「扫描目录」：只进入这门课，展开并核对完整目录，保存音视频、章节及页面完成标记，不启动播放器。扫描完成后停止。
3. 查看结果后单独点击「开始本课」：仅处理所选课程的待完成音视频。本课首轮结束后仍按原有规则刷新核对、有限重试，收尾后等待用户选择下一门。

列表中的未知数量不计作零或已完成；未完整扫描的课程没有「开始本课」按钮。没有音视频的课程仅表示没有可处理媒体，不表示文档、考试、作业或整门课程考核已经完成。

## 记录与恢复边界

- 每次显式选择均建立新的操作代数，拒绝重复选择、迟到结果和其他课程的操作。
- 扫描先写草稿，完整结果成功提交后才替换上次目录。失败或暂停保留上次完整结果和时间。
- 更新课表后，历史目录仅作参考。首页标题不能当作课程及教学班的真实 ID，需经网站课程入口重新核对。
- 用户刷新页面需要显式继续；扩展自身核对刷新只授权相同标签、课程和操作代数的一次接回，并有过期时间。
- 旧版自动任务在更新时暂停并保留记录；通过「获取课程列表」进入新流程。
- 保存失败时禁止继续导航。暂停、重置和关闭页面沿用原有停止确认及恢复限制。

## 本轮验证

- Node.js 语法检查通过；完整合成测试 443 项全部通过。
- 新增按需协议测试，覆盖列表结束等待、单课授权、未扫描禁止播放、重复及迟到操作、失败保留缓存、刷新与重启、单课播放结束停止、更新课表身份失效和保存失败禁止导航。
- 公开 UI 集成验证从课表入口开始，逐课显式扫描、单独开始本课、音视频正常推进、故障恢复、网站完成标记和不自动跨课。媒体推进由合成网站执行，扩展没有写播放时间或伪造完成。
- Chrome for Testing 147 实际加载扩展的合成页面验收通过：19 类既有状态、新版按需总览/列表/未扫描/可开始状态、设置、内页、窄屏、深色、减少动态效果、拖动与键盘；页面错误为零。
- 用户测试浏览器中的扩展已重载为 1.2.0，课程页面已刷新；旧任务处于停止状态，扩展清单及运行错误均为零。没有启动新的真实课程播放。

合成测试和界面验收不能代替平台上的整门课程实测，也不证明登录、弹窗权限或平台完成计数始终可用。课程列表只读取网站标识为正在上的课程；具体考核要求仍以平台为准。
