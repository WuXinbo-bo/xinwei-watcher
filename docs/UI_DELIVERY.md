# 芯位教育课堂助手 UI 本地调整

日期：2026-10-26。基于现有 `test2` 的 `051084f` 开展本地修改，未新建分支、提交或推送。

## 结果

将原来的长面板重组为 310px 浮窗。标题栏保留本地图片、芯位教育课堂助手、设置和收起；首页仅显示阶段、当前任务、必要进度和主要操作。课程扫描、打开统计页、目录统计、学习、等待、平台核对、重试、恢复、暂停、人工处理、存储失败、其他标签页、结束和重置分别显示真实状态。

完整信息按层级展开：

- 全部课程 → 课程章节 → 视频/音频 → 资源详情。支持未扫描、空目录、只有其他资源、读取中、读取失败、旧版无章节元数据及历史目录提示。
- 待处理事项、任务详情 → 运行日志。日志默认隐藏，空日志不预留大块空间；保留旧日志阅读锚点和新记录入口。
- 设置 → 播放目标、关于与服务、重置确认。取消重置保留正在执行的任务；确认后沿用原停止、清空和迟到消息隔离流程。

浏览课程、查看资源与定位到网页条目不启动播放，不改变队列。播放目标、自然结束与平台确认独立显示；空扫描结果不会宣称全部完成。资源使用真实记录的有效播放目标；只有当前 DOM 可确认的条目提供定位入口。

保留图片悬浮球、6px 指针拖动阈值和可视视口限制。支持系统字体、键盘焦点、深色模式、窄/矮屏与减少动态效果。页面切换动效为 160ms，不再循环环绕商业文字；外部商业链接收纳在关于页并明确标注身份。

界面偏好使用扩展私有存储并按标签页 ID 隔离，不写入网站 localStorage/sessionStorage。同一标签页在文档切换后恢复展开状态、位置、查看层级、章节与滚动位置；资源选择按任务 runId 隔离。界面偏好存储不可用时仍可操作，不影响任务存储及执行。

## 代码范围

- `assistant-ui.js`：独立展示控制器，导航、课程/资源展示及视图恢复。
- `assistant-ui.css`：作用域样式、字体、配色、动效及响应式约束，无远程字体依赖。
- `content.js`：从现有任务、目录、资源记录和媒体观察读取显示模型；接回原开始、暂停、目标设置与重置入口。课程标题识别排除助手自身 DOM。
- `background.js`：只保留可选的 `chapterTitle` 展示元数据；目录身份签名不加入该字段，兼容旧断点。
- `manifest.json`：加载独立 UI 脚本和样式，权限不增加。
- 测试与使用文档：适配新版确认和导航，替换旧 SVG 环绕广告断言。
