# 安装与使用

本目录对应 `Xinwei Course Watcher` **1.1.0 候选贡献版本**。它基于 `WuXinbo-bo/xinwei-watcher` 的 1.0.0 基线整理，保留原作者署名和 Apache License 2.0；不是原作者官方发行版。

## 第一次安装

1. 将源码包解压到固定目录；解压后的目录根部应直接包含 `manifest.json`。
2. Edge 打开 `edge://extensions/`；Chrome 打开 `chrome://extensions/`。
3. 开启开发者模式，点击“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的项目根目录。
5. 登录 Beeline AI，打开课程页面并等待目录、播放器加载完成。
6. 在扩展面板点击“开始”，先检查课程和未完成数量。

运行扩展不需要 Node.js 或开发依赖。Node.js 只用于开发检查和测试。

## 升级已有安装

1. 先在扩展面板点击“暂停”，等待状态确认。
2. 备份原加载目录，再用候选版本根目录中的文件替换对应源码。
3. 在扩展管理页点击该扩展的“重新加载”。
4. 刷新课程页面，按面板提示点击“继续”或“开始”。

更换加载目录可能导致浏览器把它识别为另一份本地扩展；任务数据是否能够继续取决于浏览器扩展存储和页面身份。任何时候只启用一份同类扩展。

## 播放目标和任务行为

- 播放目标可设为 80%–100%，默认 100%；设置会保存在扩展存储中并同步到已打开的课程页。
- 达到目标后切换到下一项；每门课程的媒体首轮处理完成后，扩展会刷新页面并核对平台延迟更新的完成状态。
- 播放、加载、目录更新或误触导航出现普通故障时，扩展会在保存的任务和资源范围内有界恢复。
- 单个异常资源最多按其课程内的重试预算处理；失败会记录课程、章节和资源，交给用户处理或继续后续课程。
- “暂停”会取消后续点击、滚动、切换、刷新和恢复；不要用网站播放器暂停代替扩展面板暂停。

## 人工处理范围

登录失效、验证码、题目、平台限制、无法确认原资源、关键状态保存失败以及网站结构变化都需要人工处理。扩展不拖动进度、不倍速、不伪造完成，也不处理文档、考试或作业。系统睡眠、退出浏览器或关闭任务标签后不能保证任务继续。
