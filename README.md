# Xinwei Course Watcher

这是一个面向 [Beeline AI](https://www.beeline-ai.com/) 学习页面的 Chrome/Edge Manifest V3 扩展。本目录是向 `WuXinbo-bo/xinwei-watcher` 提交的 **1.2.0 候选贡献版本**，基线为 `c92a3428b7fde0ebd47425a609dd7b5656b1822d`。

本版本保留原作者项目的署名和 Apache License 2.0。它不是原作者已经发布或认可的版本；是否合并由原作者审核决定。

## 功能

- 默认收起为本地图片悬浮球；点击展开 310px「芯位教育助手」，紧凑标题栏下保留赞助区、双进度课程总览和当前学习。课程与本课学习项进度放在同一卡片，当前播放只显示时间及目标标签。已完成／待完成和本课目录入口只读浏览，不切换播放。收起不会暂停任务。
- 「全部课程 → 章节 → 音视频详情」逐层查看，浏览不切换播放或改变任务顺序；未扫描的数量显示待统计。
- 资源详情的状态解释按需展开，统计更新保留阅读位置和键盘焦点。
- 任务概览默认显示课程确认、音视频确认和待处理三个指标，更多统计折叠显示；日志与设置按需打开。支持深色模式、减少动效、小屏滚动，以及同一任务跨文档恢复阅读位置。
- 标题下方提供赞助轮播与低频图标扫光，不显示轮播开关；悬停、键盘聚焦、面板收起或页面隐藏时暂停，系统减少动态效果时保持静态。完整第三方商业服务说明位于「设置 → 关于与服务」，可通过 `PROMOTION_CONFIG.enabled` 关闭。
- 半自动按需操作：先读取所有分页中正在上的课程列表，完成后等待选择，不自动进入课程。
- 每门课提供「扫描目录」与「开始本课」两个独立操作。只扫描所选课程的完整章节、音视频及平台完成标记，不启动播放器；扫描完成后再次等待选择。
- 点击「开始本课」后，仅处理本课未完成音视频，保留课内短时长优先、播放目标和有界恢复规则。本课结束后停止，由用户选择下一门。
- 未扫描课程显示未知数量；重新扫描期间保留上次完整结果，失败不会覆盖完整目录。更新课程列表后，历史目录只作参考，重新核对后才能开始本课。
- 支持 **80%–100% 播放目标**，默认目标为 100%；提供 80%／90%／100% 快捷项，有效自定义整数输入后立即保存。正常播放中的当前资源在下一次播放检查采用新值，并保存有效目标；已收尾资源不重新打开，异常恢复与课程末重试保持 100%。设置同步至已打开页面及任务默认值，平台确认仍独立记录。
- 达到目标后切换到下一项；课程首轮处理结束后刷新页面，核对平台延迟更新的完成状态。
- 对播放、页面加载、目录更新和误触导航提供有界恢复；失败会保留具体课程、章节和资源记录。
- 支持暂停、继续、重置、任务状态持久化、断点恢复和有界日志。
- 不处理文档、考试和作业，不绕过登录、验证码或平台限制。

## 安装

1. 下载或克隆本仓库，并解压到一个固定目录。
2. 打开 `edge://extensions/` 或 `chrome://extensions/`。
3. 开启开发者模式，选择“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的项目根目录。
5. 打开或刷新 Beeline AI 学习页面。

更完整的安装、升级和使用说明见 [`README-INSTALL.md`](README-INSTALL.md)。运行时不需要安装 Node.js；Node.js 仅用于开发检查和测试。

## 使用方法

1. 登录 Beeline AI 并进入课程页面。
2. 点击图片悬浮球展开面板，点击「获取课程列表」，等待分页读取完成。
3. 在「全部课程」选择一门课并点击「扫描目录」，查看章节、音视频和待完成数量。此步骤不会启动播放。
4. 在「设置」中选择 80%–100% 的播放目标，默认值为 100%；确认后单独点击「开始本课」。本课结束后，再自行选择下一门。
5. 「暂停」会停止后续操作；用户刷新页面后需要点击「继续」。收起面板只隐藏界面。登录失效、验证码、题目、平台限制或关键保存失败需要人工处理。

播放目标只决定扩展何时转到下一项，不等同于平台已经确认整门课程完成。课程末复核和异常资源重试仍受网站响应、登录状态和页面结构影响。

## 开发与测试

在项目根目录执行：

```sh
npm ci --ignore-scripts
npm run check
npm test
```

`npm run check` 检查运行脚本语法；`npm test` 使用 Node.js 测试运行器和 jsdom 执行合成页面测试。合成测试不能替代真实浏览器、平台进度记录、自动播放权限或登录状态验证。测试范围见 [`tests/README.md`](tests/README.md)，本轮 UI 调整与验证见 [`docs/UI_DELIVERY.md`](docs/UI_DELIVERY.md)。
